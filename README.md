# Task Manager SPA

Fullstack task management application built with Spring Boot (REST API) and Vanilla JavaScript SPA architecture.

---

## 🚀 Features

- User authentication (login/register)
- Create, update, and delete tasks
- SPA routing (no page reload)
- REST API backend
- Modular frontend architecture

---

## 🧱 Tech Stack

### Backend
- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- MySQL / H2

### Frontend
- HTML
- CSS
- Vanilla JavaScript (SPA)
- Fetch API

---

## 📁 Project Structure

```txt
TaskManager/
│
├── backend/        # Spring Boot REST API
├── frontend/       # Vanilla JS SPA
│   ├── app/pages
│   ├── app/components
│   ├── js/router.js
│   └── styles/
```

---

## ⚙️ How to Run
Backend

Run the Spring Boot application: TaskManagerApplication.java

Frontend

Run the frontend using a local development server:

- IntelliJ built-in server
- VSCode Live Server
- localhost environment

Then open: http://localhost:63342

---

## 🔗 Frontend–Backend Communication

Frontend communicates with the backend using:

- Fetch API
- REST endpoints
- JSON payloads
